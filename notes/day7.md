OOP (Object-Oriented Programming): A programming paradigm based on the concept of "objects," which can contain data and code: data in the form of fields (attributes), and code in the form of procedures (methods).

Class: A blueprint for creating objects. (e.g., class ClinicalTrainer:).

Method: A function that belongs to a class. (e.g., def train(self):).

__init__ (Constructor): A special method called automatically when a new object is created. It sets up the initial state of the object.

Encapsulation: The bundling of data with the methods that operate on that data, restricting direct access to some of the object's components.

DRY Principle: "Don't Repeat Yourself." If you find yourself copying and pasting the exact same training loop in Day 4, 5, and 6, it needs to be put into a reusable Class.
