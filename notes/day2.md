NumPy (Numerical Python): The foundational library for scientific computing in Python. It provides support for large, multi-dimensional matrices and a collection of high-level mathematical functions to operate on them.

Array (NumPy): A grid of values, all of the same type (usually numbers), indexed by a tuple of non-negative integers. It is the core data structure in NumPy.

PyTorch: An open-source machine learning framework originally developed by Meta (Facebook). It is specifically designed for deep learning, offering automated calculus and hardware acceleration.

Tensor (PyTorch): The PyTorch equivalent of a NumPy array. It is a multi-dimensional matrix, but with the added abilities to track gradients (derivatives) and execute operations on a GPU.

CPU (Central Processing Unit): The main processor of a computer. Great for complex, sequential tasks (like running your operating system), but slower at doing millions of simple math problems at once.

GPU (Graphics Processing Unit): A specialized processor originally built for rendering video games. Because rendering graphics requires doing millions of simple math problems simultaneously (parallel processing), GPUs are the perfect hardware for training neural networks.
